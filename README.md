# 🌿 Forest Fortune (Лесная Удача)

Добро пожаловать в **Forest Fortune** — премиальный Telegram Mini App слот, выполненный в волшебном лесном стиле. 

## 🎰 О проекте
Это полноценная игра-слот (Social Casino), созданная с нуля для Telegram. Игроки крутят барабаны, ловят диких духов леса (Wild), собирают магические грибы (Scatter) для фриспинов и срывают глобальный джекпот.

## ✨ Особенности
- **Премиальная графика:** Символы в виде лесных духов, кристаллов и грибов (PNG с прозрачным фоном).
- **Безопасный баланс:** Все данные хранятся на сервере (Cloudflare KV), накрутить монеты через консоль невозможно.
- **Оплата Stars:** Покупка виртуальных монет за официальную валюту Telegram (XTR).
- **Геймплей:** 21 линия, Wild-символы, Scatter (10 фриспинов x2), Автоспины, Колесо Фортуны и Глобальный Джекпот.
- **Реферальная система:** Приглашай друзей и получай бонусы.
- **Игра 18+:** Виртуальные монеты не имеют денежной стоимости и не подлежат выводу.

## 🛠 Технический стек
- **Frontend:** Vanilla HTML5 / CSS3 / JavaScript (Telegram WebApp API).
- **Backend:** Cloudflare Workers (Serverless).
- **Database:** Cloudflare KV Namespace.
- **Audio:** Web Audio API (динамическая генерация звуков леса).

## 🚀 Деплой
Проект настроен на автоматический деплой через Cloudflare Workers Builds (связан с GitHub).
